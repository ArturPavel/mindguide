# How to build
<code>cd</code> into the main folder and execute <code>npm run build</code>
> [!IMPORTANT]  
> Dependencies: Python 3.10 or newer, pip, Node.js, npm

# How to run
After the application has been built <code>cd</code> into the main folder and execute <code>npm run start</code>
